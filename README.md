# 保溫工程配管圖分析系統

本系統提供簡易的保溫工程配管圖分析功能，能夠上傳圖紙並進行測量與標註。

## 部署到 GitHub Pages

1. 將此專案上傳至你的 GitHub 倉庫。
2. 在倉庫的設定（Settings）中，找到 GitHub Pages 部分。
3. 選擇 `main` 或 `master` 分支作為來源，然後保存。
4. 前往指定的頁面，開始使用系統。

## 功能

- 上傳配管圖紙
- 測量與標註功能
- 基本報告生成

## 建議擴展

未來可以考慮擴充的功能包括：
- 多種分析方法
- 圖層管理
- 進階報告生成

## 功能介紹

1. **上傳功能**：用戶可以通過拖放或點擊上傳配管圖紙。
2. **測量與標註**：提供基本的測量工具及標註功能。
3. **報告生成**：用戶可以生成簡易的分析報告。
4. **響應式設計**：界面適用於不同設備，確保最佳使用體驗。

## 系統擴展建議

- **進階分析功能**：如熱損失計算、保溫材料選擇等。
- **資料庫整合**：將材料和規格資料儲存於一個後端系統中，便於擴展。
- **用戶賬號管理**：提供用戶登錄和數據儲存功能。

將這些文件上傳至 GitHub 並啟用 GitHub Pages，即可立即使用這套完整的保溫工程配管圖分析系統。
